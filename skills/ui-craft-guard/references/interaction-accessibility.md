# 交互与无障碍验收，优先于“去 AI 味”

## 最小真实操作链

- 主要目标：从进入页面到完成一次任务是否无需猜测下一步。
- 表单：关联 label 与 input；校验错误字段可定位；失败时保留已有输入；重复提交避免误操作。
- 导航：链接有真实目标，按钮有真实动作；无 `href="#"` 假链接；关闭对话框后焦点合理恢复。
- 状态：禁用说明原因、加载可观察、成功明确、错误可恢复、空列表有下一步。
- 键盘：Tab 顺序符合信息流；每个可操作控件有可见焦点；ESC 适用时关闭模态层。
- 屏幕阅读器：语义元素优先于 div click；图标按钮有可访问名称；重要视觉信息不只靠颜色传达。
- 减少动画：遵从 `prefers-reduced-motion`，避免不必要视差和强制滚动动画。
- 窄屏：允许内容增高但不让横向溢出阻断主任务；检查触控目标实际面积和间距。

## 标准/审美的边界

WCAG 文本对比度（普通 4.5:1、大字 3:1）是常见 AA 约束；更完整的例外、非文本对比、焦点标准必须以 W3C 原文为准。0.5px 边框或 12px 字号来自设计建议，不是 WCAG 最低值。

静态审计脚本不可能真实验证交互、ARIA 或视觉对比度；必须用浏览器工具/辅助技术做回归，若不可用则列为未执行。不要把静态自动扫描报告写成 WCAG 合规认证。

参考：https://www.w3.org/TR/WCAG22/
